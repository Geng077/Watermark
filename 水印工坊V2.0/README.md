# 水印工坊 V2.0

完全本地运行的 PDF / Word / 图片水印工具，界面采用液体玻璃风格，支持白天模式、夜间模式和跟随系统。

## 新增能力

- 液体玻璃界面与三态主题：白天 / 夜间 / 跟随系统；带玻璃高光扫过和果冻式回弹。鼠标跟随光效只在首屏显示，选择文件后自动关闭，避免干扰水印设置。
- 首屏主按钮 + 三步流程条（选择文件 → 调整水印 → 下载），上传后自动高亮下一步区域。
- 支持 Word `.docx`：水印以页面级 PNG 写入 Word 页眉，与预览使用同一张 SVG 图案；文档正文和格式保持可编辑。
- Word 的“应用于”支持整篇文档 / 仅首页（Word 原生页眉水印能精确控制的两种范围）。
- 输出格式可选择：
  - PDF → PDF 文档
  - PDF → 逐页 PNG / JPEG 图片包（ZIP）
  - Word `.docx` → 带水印 DOCX
  - 图片 → PNG / JPEG / WebP
- Word 预览使用 docx-preview 渲染，并按 Word 页面高度重复页面级水印；输出 Word 使用同一张页面级水印图片，因此图案、字号、角度、透明度和平铺位置与预览一致（连续排版的分页边界仍为近似）。

## 原有功能

- PDF（多页）、PNG / JPG / JPEG / WEBP 图片
- 文字水印：思源黑体 / 思源黑体粗体 / 马善政楷体 + Helvetica / Times / Courier
- 真实字体加粗开关（Noto Sans SC Bold）
- 字号、颜色、透明度、倾斜角度、字间距；滑块和数字输入双向同步
- 描边、阴影、文字换行
- 图片水印（PDF/图片支持；Word 目前只支持文字水印）
- 平铺 / 单个布局、九宫格定位、边距与偏移
- 水印层级：内容下方 / 内容上方（PDF）
- 指定页面范围（PDF）
- 样式预设：默认浅印（+45°）、机密居中、红章、斜排平铺、浅色平铺

## 使用

**方式一（推荐）**：双击 `启动.bat`，自动打开浏览器并启动本地服务。

**方式二**：直接双击 `index.html`（字体已内嵌，可离线使用）。

**方式三（发给朋友）**：发送 `水印工坊V2.0-单文件版.html`，对方双击即可使用。

所有处理都在浏览器本机完成，文件不会上传到服务器。


## 格式限制

- 不做 PDF → Word 的伪转换；PDF 转 Word 需要专业转换服务。
- 不支持旧版 `.doc`、`.docm`；请先另存为 `.docx`。
- Word 文档目前只支持文字水印，不支持图片水印。
- Word 原生页眉水印不能按任意页范围应用；任意页范围请使用 PDF 流程。V2.0 的 Word 选项为“整篇文档 / 仅首页”。
- Word 原生页眉水印位于正文下方，不提供不可靠的“内容上方”切换。
- Word 中的水印本身是页眉图片（不是可编辑文字），正文内容仍然完全可编辑。
- Word 预览与实际 Word/WPS 排版可能有细微差别；输出文件使用标准 Word 页眉图片水印，正文保持原样。
