# 水印工坊
✨ 完全本地离线运行的水印工具，拥有基础的水印能力，浅/深色玻璃拟态风格，无需服务器，不上传你的文件。

> 本项目基于 MIT 协议开源，所有处理在浏览器本地完成，你的文件不会上传到任何第三方。

## 🆕 V2.0 更新亮点
- 新增 Word `.docx` 水印：支持页眉水印，正文格式保持可编辑；支持【整篇文档 / 仅首页】两种模式
- 多格式输出：PDF 可输出 PDF；图片包可输出 PNG / JPEG / WebP；Word 输出 DOCX
- 三态主题：白天、夜间、跟随系统自动切换，主题配置自动保存
- UI 升级：苹果液体玻璃质感，光影、悬浮卡片、果冻回弹动效
- 流程重构：选择文件 → 调整水印 → 下载，操作路径更清晰

## 📦 支持文件类型
- PDF（多页）
- PNG / JPG / JPEG / WebP 图片
- Word DOCX
