# 水印工坊

一个完全本地运行的 PDF / 图片水印工具，仿照 pdf24.org 的水印功能，界面走深色玻璃质感风格。

## 功能

- 支持 PDF（多页）、PNG / JPG / JPEG / WEBP 图片
- 文字水印：多字体（思源黑体 / 思源黑体粗体 / 马善政楷体 + Helvetica / Times / Courier）
- 字体加粗开关（中文使用真实 Noto Sans SC Bold，不是简单描边）
- 字号、颜色（色板 + 自定义取色）、不透明度、倾斜角度、字间距；滑块与数字输入双向同步
- 描边、阴影效果，文字支持换行
- 图片水印：上传 PNG / JPG / SVG（建议透明 PNG），缩放、旋转、透明度
- 布局：平铺（可调横纵间距）或单个（九宫格定位 + 边距 + 微调偏移）
- 水印层级：默认放在文档内容下方，也可以切换为内容上方
- 指定页面范围（如 `1-3,5,7`）
- 样式预设：默认浅印（+45°）/ 机密居中 / 红章 / 斜排平铺 / 浅色平铺
- 所见即所得预览：PDF 预览直接使用与下载相同的生成引擎，预览什么样下载就什么样
- 逐页翻看

## 使用

**方式一（推荐）**：双击 `启动.bat`，会自动打开浏览器并启动本地服务。

**方式二**：直接双击打开 `index.html` 即可使用（字体已内嵌，可离线使用）。

**方式三（发给朋友）**：直接把 `水印工坊-单文件版.html` 发给对方，双击即可使用，不需要安装任何东西。

所有处理都在本机完成，文件不会上传到任何服务器。

## 给朋友用 / 部署成公开网站

这是一个纯静态网站，不需要后端。任选一种：

- 把 `水印工坊-单文件版.html` 直接发给朋友，对方双击打开即可。
- 打开 [Netlify Drop](https://app.netlify.com/drop)，把整个 `pdf-watermark` 文件夹拖进去，几秒后会得到一个可分享的网址。
- 把整个文件夹上传到 GitHub Pages、Vercel 等静态托管服务，也能得到公开网址。

部署后朋友访问网址即可使用，处理后文件仍只在对方浏览器里处理，不会上传。

## 文件说明

- `index.html` 页面结构
- `styles.css` 样式
- `app.js` 核心逻辑（预览 + 水印生成）
- `fonts-data.js` 内嵌的子集化中文字体（覆盖国标常用汉字）
- `vendor/` pdf-lib、fontkit、pdf.js 三个开源库
- `水印工坊-单文件版.html` 适合直接分发/双击使用的单文件版本（约 22 MB，首次打开稍慢）
